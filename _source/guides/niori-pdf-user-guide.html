## niori-pdf User Guide A practical, illustrated guide to creating PDF documents with niori-pdf. This guide is intended for people who want to create documents rather than develop the library itself. It introduces the main concepts and walks through common document-generation tasks, from a first PDF to complete reports. ### Download [Download the niori-pdf User Guide (PDF, 2.5 MB)](/assets/downloads/documentation/niori-pdf/niori-pdf-user-guide.pdf) ### What's inside - **Getting started:** installation, your first PDF, and the Flow and Primitives APIs. - **Working with content:** text, paragraphs, lists, footnotes, tables, images, and charts. - **Page layout:** boxes, columns, floats, and cross-references. - **Graphics and codes:** drawing, barcodes, and QR codes. - **Advanced features:** interactive forms, embedded fonts, Unicode, and PDF/A. - **Practical recipes:** invoices, certificates, project one-pagers, and a complete report walkthrough. - **Troubleshooting:** common questions and solutions. ### Technical reference For the complete API and implementation reference, see the [niori-pdf technical manual](/documentation/niori-pdf/).
