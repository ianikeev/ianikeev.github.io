2 Installation ¶

The package is built for MELPA; until published, install from a checkout by adding the directory to load-path and requiring niori-pdf. The MELPA recipe is: 

(niori-pdf :fetcher github :repo "YOUR-NAME/niori-pdf")

Running make byte-compiles the library and builds this manual: 

make            compile + docs/niori-pdf.info
make test       run the ERT suite
make dist       release tarball

The info target needs makeinfo (the Debian/Ubuntu package is texinfo); the compile and test targets need only Emacs.
