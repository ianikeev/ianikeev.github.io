12 Barcodes and QR codes ¶

niori-pdf-barcodes.el ports cl-pdf’s bar-codes.lisp (Code 128 by Lars Rustemeier) and adds Code 39 and EAN-13, plus the module-matrix drawer shared with the QR encoder (niori-pdf-qrcode.el). All barcodes are drawn with path primitives, so no fonts are embedded for the bars themselves.

Function: niori-pdf-barcode-code128 string x y &key height width font font-size start-stop-factor show-string color ¶

Code 128 with automatic charset selection (C for even-length all-digit strings, B otherwise). The bars rise upward from the baseline y; the human readable text is drawn below it.

Function: niori-pdf-barcode-code39 string x y &key height width narrow show-text font font-size color ¶

Code 3 of 9 (0-9 A-Z - . space $ / + %).

Function: niori-pdf-barcode-ean13 string x y &key height width font font-size color ¶

EAN-13; accepts 12 or 13 digits (the check digit is computed for 12).

Function: niori-pdf-barcode-qr matrix x y &key point-size color ¶

Draw a module matrix (list of lists of 0/1) as filled squares, row 0 at the anchor with the y axis running downward (the port of cl-pdf’s draw-qr-code).
