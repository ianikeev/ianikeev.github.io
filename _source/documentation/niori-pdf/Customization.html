17 Customization ¶

User Option: niori-pdf-compression ¶

See Compression and zlib.

User Option: niori-pdf-gzip-program ¶

External gzip program used when niori-pdf-compression is gzip (default "gzip").

User Option: niori-pdf-deflate-min-size ¶

Minimum stream size for compression (default 100).

User Option: niori-pdf-deflate-window ¶

LZ77 window (default and maximum 32768).

User Option: niori-pdf-deflate-max-chain ¶

LZ77 hash-chain search depth (default 16).

User Option: niori-pdf-pdfa-base14-substitutions ¶

See PDF/A-2b archival output.
