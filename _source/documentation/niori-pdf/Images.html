8 Images ¶

Function: niori-pdf-image-from-file spec ¶

Load an image from a file path or a plist (:type jpeg|png :data BYTES). JPEG files are embedded as DCTDecode XObjects (dimensions and colorspace parsed from the markers; grayscale, RGB and Adobe-inverted CMYK are supported). PNG files are fully decoded in Elisp: chunk parsing, zlib inflation, row un-filtering (None, Sub, Up, Average, Paeth), color types 0/2/3/4/6, bit depths 1/2/4/8 and 16 (downsampled to 8). Palette images with a tRNS chunk and RGBA/gray-alpha images get an alpha /SMask. Interlaced PNGs are rejected.

Function: niori-pdf-draw-image image x y &optional dx dy ¶

Draw an image object with its lower-left corner at (x, y), scaled to dx x dy points (default: one point per pixel).
