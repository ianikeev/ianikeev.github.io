11 AcroForms (Interactive Forms) ¶

niori-pdf-acroforms.el adds interactive form fields (PDF 32000-1 chapter 12.7). Call niori-pdf-acroforms-enable once inside the document, then create fields with page coordinates (origin bottom-left, like niori-pdf-add-link). Every field gets a generated appearance stream, so the form renders correctly even in viewers that ignore NeedAppearances.

Function: niori-pdf-acroforms-enable doc &optional need-appearances ¶

Enable form collection for doc. With need-appearances the catalog gets /NeedAppearances true (by default niori-pdf provides its own appearance streams and omits the flag).

Function: niori-pdf-acroforms-text-field doc name x y w h &key value font font-size tooltip multiline password read-only align max-len bg bc ¶

Text field. align is 0 (left), 1 (center) or 2 (right).

Function: niori-pdf-acroforms-checkbox doc name x y w h &key checked read-only tooltip bg bc mark ¶

Check box with a path-drawn check mark appearance.

Function: niori-pdf-acroforms-choice doc name x y w h options &key value editable tooltip read-only bg bc mark ¶

Dropdown (combo) choice; options is a list of strings.

Function: niori-pdf-acroforms-radio-group doc name buttons &key value read-only tooltip bg bc mark ¶

Radio group; buttons is a list of (x y size export-string) tuples on the current page.

Function: niori-pdf-acroforms-push-button doc name x y w h &key caption tooltip uri font font-size read-only bg bc fg ¶

Push button; with uri it triggers a URI action.

Function: niori-pdf-acroforms-set-value doc name value ¶

Update a field’s value (and appearance) after creation: strings for text and choice fields, booleans for check boxes, export strings for radio groups.
