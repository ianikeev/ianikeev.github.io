5 Documents and pages ¶

Macro: niori-pdf-with-document (props) body… ¶

Create a document context and run body inside it. props is a literal plist; supported keys: :title :author :subject :keywords :creator :producer :page-width :page-height :compression. The document is the value of the variable niori-pdf--doc during body and the value of the whole form.

Macro: niori-pdf-with-page (props) body… ¶

Create a page in the current document. props: :width :height (points). All drawing forms inside operate on this page.

Function: niori-pdf-save doc file ¶

Write a finished document to file (classic xref table, trailer with catalog and info dictionary). Producer and creation date are filled in automatically; info strings are written as UTF-16BE so any Unicode title works.
