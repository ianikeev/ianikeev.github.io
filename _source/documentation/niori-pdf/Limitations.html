18 Limitations and roadmap ¶

The feature set of the original library that matters for niori.el is ported: the object model and writer, pure-Elisp DEFLATE, Base-14 fonts with AFM metrics, kerning pairs and Symbol/ZapfDingbats native encodings, TrueType subsetting, CFF/OTF embedding with CFF-level subsetting, TrueType collections, Type 1 font embedding (.pfb/.pfa with eexec/charstring width extraction), JPEG/PNG images, the full vector graphics layer, document outlines, AcroForms, bar codes, chart helpers, glyph outline drawing, PDF/A-2b archival output, and a cl-typesetting style flow engine with Knuth-Plass line breaking and TeX-pattern hyphenation.

A complete showcase is examples/alice-book.el, which typesets Lewis Carroll’s Alice’s Adventures in Wonderland as an 86-page A5 book with serif body text, sans-serif headings, running heads, a linked table of contents and a QR colophon - all from Elisp.

Remaining differences from the Common Lisp originals:

  • Font features beyond cmap/glyf/CharStrings (hinting engines, GSUB/GPOS shaping) are not used.
  • AcroForm JavaScript actions and digital signatures are out of scope.
  • Hyphenation patterns ship for English (American and British), German, French, Spanish (one set - the RAE/ASALE orthography is common to all Spanish variants), Italian, Portuguese (one set for pt-PT and pt-BR), Esperanto, Ukrainian and Russian. Other languages can be added with the same generator.
