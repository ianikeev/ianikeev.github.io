6 Text and Fonts ¶

Function: niori-pdf-set-font name size ¶

Select the current font. name is one of:

  • a base-14 name ("Helvetica", "Helvetica-Bold", "Helvetica-Oblique", "Helvetica-BoldOblique", "Times-Roman", "Times-Bold", "Times-Italic", "Times-BoldItalic", "Courier", "Courier-Bold", "Courier-Oblique", "Courier-BoldOblique", "Symbol", "ZapfDingbats"); drawn unembedded with the real Adobe AFM metrics,
  • a path to a .ttf TrueType, .otf OpenType/CFF or .ttc TrueType collection file, which is parsed, subsetted and embedded,
  • a path to a .pfb or .pfa Type 1 font file, which is embedded whole with a /FontFile stream (see Type 1 fonts (.pfb/.pfa)),
  • a plist (:file PATH :index N) selecting member N (0-based) of a TrueType collection.

Base-14 fonts ¶

The base-14 fonts are drawn from the real Adobe AFM metrics (embedded in niori-pdf-metrics.el, generated from the freely redistributable core-14 AFM files). Text is encoded with WinAnsiEncoding (Latin-1 plus the Windows special characters such as the euro sign, smart quotes and dashes). Characters without a WinAnsi mapping are drawn as ‘?’.

TrueType, OpenType/CFF and TrueType collections ¶

niori-pdf-set-font accepts .ttf, .otf and .ttc paths. TrueType and OpenType/CFF fonts are parsed (cmap formats 0/4/6/12, head, hhea, maxp, hmtx, loca, glyf, name, post, OS/2), a glyph subset covering exactly the characters you draw is built (composite glyphs are closed transitively, original glyph ids are retained) and the result is embedded as a Type0 / CIDFontType2 (TrueType) or CIDFontType0 (CFF) font with Identity-H encoding and a ToUnicode CMap, so text extraction keeps working. Missing glyphs fall back to .notdef.

A .ttc TrueType collection packs several fonts into one file; niori-pdf reads the member selected by index (default 0). Use niori-pdf-ttf-collection-fonts to list the members and pass a plist spec to choose one: 

(niori-pdf-ttf-collection-fonts "/usr/share/fonts/truetype/wqy/wqy-zenhei.ttc")
  ⇒ ((0 "WenQuanYiZenHei" "WenQuanYi Zen Hei")
           (1 "WenQuanYiZenHeiMono" "WenQuanYi Zen Hei Mono")
           (2 "WenQuanYiZenHeiSharp" "WenQuanYi Zen Hei Sharp"))

;; draw with the second member of the collection:
(niori-pdf-set-font '(:file "/usr/share/fonts/truetype/wqy/wqy-zenhei.ttc"
                      :index 1)
                    12)
Function: niori-pdf-ttf-collection-fonts path ¶

List the fonts of the TrueType collection at path. Returns a list of (INDEX PS-NAME FAMILY).

Function: niori-pdf-text-width string font &optional size ¶

Width of string in points at size, using the same metrics the viewer will use. This is the measurement primitive of the flow engine. font may be a font object, a base-14 name, a font file path or a (:file :index) collection spec.

  • Type 1 fonts (.pfb/.pfa)

6.1 Type 1 fonts (.pfb/.pfa) ¶

Type 1 font programs are embedded whole — no subsetting (Type 1 subsetting would mean rewriting the private dictionary; the fonts are small anyway). The parser handles both container formats: the binary .pfb segment structure (0x80 0x01 ASCII, 0x80 0x02 binary, 0x80 0x03 EOF markers, with the post-eexec hex trailer mapped to /Length3) and the ASCII .pfa form (clear text up to the eexec line, then hex-encoded binary).

No companion .afm file is needed: niori-pdf decrypts the eexec section (key 55665) and reads the advance width of every glyph directly from the /CharStrings charstrings (key 4330, the first two operands of hsbw), so the PDF /Widths array and the measurement metrics are derived from the font program itself. The result is a /Subtype /Type1 font with /Encoding /WinAnsiEncoding and a /FontDescriptor carrying /FontName, /FontBBox, /ItalicAngle, /CapHeight, /StemV (from the private /StdVW) and the standard flags (fixed-pitch, italic). 

;; URW Nimbus Roman, metric-compatible with Times-Roman:
(niori-pdf-set-font
 "/usr/share/fonts/X11/Type1/NimbusRoman-Regular.pfb" 10.5)

Caveat: the text you draw is mapped through WinAnsiEncoding glyph names, so the font must contain the standard Latin glyph names (all the URW Base-35 fonts do).
