13 QR codes ¶

niori-pdf-qrcode.el is a full QR Code model 2 encoder (ISO/IEC 18004) written for niori-pdf - cl-pdf only draws a pre-computed matrix. Features: byte mode (UTF-8, no ECI segment), versions 1-10, all four error correction levels, Reed-Solomon error correction over GF(256) with the proper block structure and interleaving, all eight mask patterns scored with the ISO penalty rules N1-N4, BCH(15,5) format information and BCH(18,6) version information for versions 7-10. Every matrix emitted by the test suite round-trips through an independent QR decoder.

Function: niori-pdf-qr-encode string &key ecl version ¶

Return (MATRIX . VERSION); matrix is a list of N lists of N integers (1 = dark, 0 = light), row 0 at the top. ecl is the symbol L, M, Q or H (default M); version forces a version 1-10, otherwise the smallest one that fits is used.

Function: niori-pdf-barcode-qr-string string x y &rest keys ¶

Encode string and draw the symbol with its top-left module corner at (x, y). Keys: :ecl :version :point-size :color. Returns (WIDTH HEIGHT VERSION).
