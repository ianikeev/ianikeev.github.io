14 Charts ¶

niori-pdf-charts.el ports the chart helpers of cl-pdf’s chart.lisp: pie charts and axis bar charts drawn as vector paths with legend and value labels.

Function: niori-pdf-pie-chart data x y radius &rest keys ¶

data is a list of (LABEL VALUE COLOR); keys: :title :show-values :label-font :label-size.

Function: niori-pdf-bar-chart data x y width height &rest keys ¶

data as above; keys: :title :y-axis-labels :grid-color :bar-gap :show-values :label-font :label-size.
