1 Overview ¶

niori-pdf generates PDF 1.4 files entirely inside GNU Emacs. It is a port of the core of Marc Battyani’s Common Lisp library cl-pdf, plus a practical subset of its layout engine cl-typesetting, adapted to idiomatic Emacs Lisp.

The reason for the port: org-export and latex make Emacs depend on a TeX installation. A standalone Emacs application (such as niori.el) cannot require TeX, Ghostscript or a headless browser on the user’s machine. niori-pdf writes standard PDF files with nothing but a running Emacs; its only dependency is Emacs 27.1 or newer.

The package is split into modules, each corresponding to a layer of the original library:

  • niori-pdf-core.el — object model, file writer, xref, compression (see Compression and zlib)
  • niori-pdf-metrics.el — generated AFM width tables for the base-14 fonts
  • niori-pdf-fonts.el — font registration, WinAnsi encoding, text measurement
  • niori-pdf-ttf.el — TrueType/OpenType parsing, subsetting, embedding (including TrueType collections)
  • niori-pdf-type1.el — Type 1 font (.pfb/.pfa) parsing and embedding
  • niori-pdf-content.el — text and vector graphics operators (the pdf-base/text/pdf-geom equivalents)
  • niori-pdf-images.el — JPEG and PNG XObjects
  • niori-pdf-flow.el — the typesetting engine (see The Flow Engine)
  • niori-pdf-pdfa.el — PDF/A-2b archival output (see PDF/A-2b archival output)
