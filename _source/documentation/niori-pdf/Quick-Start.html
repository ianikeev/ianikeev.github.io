3 Quick Start ¶

(require 'niori-pdf)

(niori-pdf-with-document (:title "Hello")
  (niori-pdf-with-page ()
    (niori-pdf-set-font "Helvetica-Bold" 24)
    (niori-pdf-draw-text 72 720 "Hello, PDF world")
    (niori-pdf-set-font "Helvetica" 12)
    (niori-pdf-draw-text 72 690 "Pure Emacs Lisp."))
  (niori-pdf-save niori-pdf--doc "/tmp/hello.pdf"))

Coordinates are PDF points (1/72 inch), origin at the bottom-left of the page, y pointing up — exactly like cl-pdf. The default page is A4 portrait (595.28 x 841.89 pt); pass :width/:height to niori-pdf-with-page for anything else.

3.1 Quick start: the flow engine ¶

The flow engine lays out whole documents for you — justified paragraphs, headings, tables, lists, images — with automatic page breaks, running headers and a table of contents: 

(require 'niori-pdf)

(niori-pdf-flow-generate
 (lambda ()
   (niori-pdf-with-flow-document
       (:title "Q4 report" :footer-fn #'niori-pdf-flow-page-footer)
     (niori-pdf-flow-heading "Q4 report" :level 1)
     (niori-pdf-flow-paragraph
      "Justified text with real font metrics, wrapped and paginated
automatically, hyphenated with TeX patterns."
      :align 'justified)
     (niori-pdf-flow-itemize '("first point" "second point"))
     (niori-pdf-flow-table
      (list :header ["Region" "Revenue"]
            :rows '(("North" "156") ("South" "134"))))
     (niori-pdf-flow-toc)))
 (niori-pdf-flow-save niori-pdf--doc "/tmp/report.pdf"))

When niori-pdf-flow-toc or cross-reference points are used, niori-pdf-flow-generate runs the builder a second (at most six) time so every page number in the output is correct.
